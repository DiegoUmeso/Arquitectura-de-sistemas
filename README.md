# API de Pokemones

API REST desarrollada en TypeScript utilizando Express.

## Requisitos

- Node.js
- npm

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

El servidor se ejecutará en:

```
http://localhost:3000
```

## Endpoints

- GET /pokemones
- POST /pokemones
- PUT /pokemones/:id
- PATCH /pokemones/:id
- DELETE /pokemones/:id

No utiliza base de datos; la información se almacena temporalmente en memoria.
